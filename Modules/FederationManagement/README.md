# FederationManagement
Standalone .NET 8/C# 12 module sample with in-memory store. The `Contracts/MockContracts.cs` file provides self-contained IModule and enabled SportsFederation license filter contracts; replace them with host contracts during integration. Register IFederationLicense and FederationLicenseGuardFilter in DI, add controllers as an MVC application part, and configure Razor view discovery. Add authentication/permissions and a persistent repository in the host. Pairing sorts active athletes by belt/rank and pairs neighbors; an odd athlete gets a bye. Grade = clamp(base rank + wins - losses, 1, 10); points = wins * 3. Add antiforgery tokens in host-rendered forms.
